# Timer App Basic
A lightweight stopwatch app with nothing more than a stopwatch. Completely made in React + Vite. 

## Stack
- React
- Vite
- TypeScript
- TailwindCSS

## Setup
1. Clone the repo with `git clone https://github.com/muhammedaadhilv69-crypto/timer-app-basic/`
2. `cd timer-app-basic`
3. Install packages `npm install` or `pnpm install`
4. Run dev server `pnpm dev`
OR
5. Create build `pnpm build`
6. Run build server `pnpm start`
